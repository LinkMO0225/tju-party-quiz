## 3.2fixed — 2026-10-11

### 修复｜底部按钮左右颠倒

选择题底部的两个按钮位置反了——「**提交**」在左、「**不会，看答案**」在右。

问题出在这：判分之后，底部的按钮是「上一题」（左）和「**下一题**」（右）。所以刷题时拇指会习惯性**一直按右下角**前进。可到了答完题、还没提交那一步，右下角变成了「不会，看答案」——**习惯性一按，就跳过了这道题**。

现在把顺序掉过来：

| 位置    | 未判分时            | 判分后     |
| ----- | --------------- | ------- |
| 左     | 不会，看答案          | 上一题     |
| **右** | **提交答案 / 确认提交** | **下一题** |

**右下角永远是「往前走」那个键**，拇指不用挪，也不用担心误按跳题。单选、多选、错题强化模式都改了。

## 3.1fixed — 2026-10-10

### 修复｜判分框的字母对不上

开了「选项乱序」以后，判分框里那句「**你选的是 X**」用的是题库里的**原始字母**，不是你屏幕上看到的顺序——于是会出现荒唐的一幕：**「你选的是 AC」「正确答案：AC」，却判你错。**

现在两处统一成**屏幕上的那套字母**：

| 判分框里的字  | 修复前            | 现在         |
| ------- | -------------- | ---------- |
| 你选的是 ？？ | 题库原始字母（跟屏幕对不上） | **屏幕字母** ✅ |
| 正确答案：？？ | 屏幕字母           | 屏幕字母       |

**判分本身一直是对的**（内部仍按原始字母比对），这次只是把显示对齐，不再自相矛盾。

### 新增｜多选题也能「不会，看答案」

以前只有单选题底部有「不会，看答案」，多选题不会就只能硬着头皮蒙。

现在多选底部也有这个按钮，点一下直接亮出答案、跳过本题。

### 新增｜单选题「确认提交」（可关）

以前单选题**点一下就直接判分**，手滑选错也没得改。

现在改成两步：

1. 点选项 → 高亮选中（**这时还能改选**）
2. 点「**确认提交**」→ 才判分

首页「其他」里新增开关 **「单选需确认」**，**默认开**。觉得单选多点一下慢，把它关掉，立刻回到原来的"点即判"。

### 一个小提示

上一版说过「别按 A/B/C/D 背答案，按选项内容记」。这条现在更成立了：**判分框里显示的字母，已经完全跟随你屏幕上的选项顺序**，不会再有两套字母打架的情况。

## 2.1fixed — 2026-10-10

### 新增｜错题强化 · 无限刷

刷到错题不用再等整轮刷完。测验首页会多出一个橙色的「错题强化 · 无限刷」按钮，按钮上直接写着当前范围里有多少道错题。

进去之后：正常题乱序循环出，**每做 3 道插一道错题**。

| 情况    | 结果                |
| ----- | ----------------- |
| 强化题答对 | 从错题池**永久移除**，不再出现 |
| 强化题答错 | 留在池里，过几道再来        |
| 普通题答错 | 自动加入错题池           |

- 第一题直接上强化题，不浪费时间
- 顶栏显示「第 N 题」，进度条按**攻克比例**走
- 强化题在题干上方有蓝色标识，写明池里还剩几道
- 池子清空 → 通关页；中途退出不丢进度

### 新增｜选项乱序（可关）

同一道题每次进入，A/B/C/D 的顺序都会重新打乱——防止背答案的**位置**而不是内容。

首页「其他」里有开关，**默认开**；关掉后按原书顺序显示。开关对错题强化模式同样生效。

### 改进｜填空卡片可以撤回重背

原来点卡片只能一路往下翻，想再背一遍没机会。

现在：**点一下展开答案，再点一下收起**，可以反复。翻页交给底部的「下一张」按钮。

### 修复

- **刷题进度重置一次**。2.0 把填空题从刷题里剔除时，题库下标整体前移了，旧记录已经和题目对不上（错题会串位）。新旧数据混在同一个存储里没法可靠还原，所以清空重来。
- 背诵进度和卡片标记**不受影响**。
