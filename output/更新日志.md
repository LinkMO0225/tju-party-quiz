## 6.0 — 2026-11-05

### 题库更新至第九十一期

- **新增第九十一期**：册子里的选择与填空题专题（真题选讲 + 题型专练）已全部录入，共 57 道选择题、22 道填空题。其中 **12 道是全新题目**，例如李大钊《我的马克思主义观》、陈天华与《辛丑条约》、八七会议、六项基本要求、天大第十一次党代会。
- **重复题按最新表述覆盖**：45 道与旧题库重复的题，题干、选项、答案一律换成 91 期版本。比如《中国共产党发展党员工作细则》那题，旧版还写着「基本纲领、基本经验、基本要求」，新版已改为「基本理论、基本路线、基本方略」——考试按新细则出，旧表述不能再用。
- **分类改为互斥**：范围筛选调整为「91期相关 57 / 往年真题 207 / 网上党课 322」，三者不再重叠，加起来正好是全部 586 道。想要一次刷完全部题的人，点「全部」不会遇到重复题。
- **顺手清掉 5 组历史重复**：旧题库里同一道题在往年真题和网上党课各存了一份（只差标点或选项顺序），共 5 组。这次保留权威版本（考卷优先于党课整理稿），另一份合并隐藏——题目没删，只是不再重复出现在「全部」里。
- **往期内容不再消失**：原「第90期相关」里没被 91 期收录的 40 道题，并入往年真题；网上党课原有 337 道，其中 10 道被 91 期收录，入口归到「91期相关」，其余 327 道留在党课，再扣掉 5 道合并的重复题，实际可见 322 道。
- **填空卡片整套替换**：87 张旧卡片换成 91 期题型专练的 22 张。旧卡片的「已背」「已标记」记录会重置——卡片内容完全变了，按位置沿用旧标记只会张冠李戴。
- **刷题进度不受影响**：题目顺序只在末尾追加，已有 579 道题的下标一个没动，此前做对的、做错的记录都还在。

### 界面改版

- **背景**：原来是纯灰底，现在铺了三层极淡的环境光（冷蓝 / 青 / 暖），固定在底层只绘制一次，滚动时不动。
- **卡面**：半透明白 + 顶边内高光 + 三层阴影，取代原来的 1px 灰边框。层次靠光影，不靠线条。
- **选项**：改成有厚度的按键，字母从圆点改为圆角键帽；按下去有回弹，选中时带一圈淡蓝辉光。
- **动效**：缓动曲线换成先快后慢；换题时选项按 40 毫秒间隔依次浮现；进度条 0.5 秒缓出。系统开启「减少动态效果」时全部关掉。
- **液态玻璃只做在两条固定底栏**：内容会从底栏下面滚过去，那里做真模糊。列表里的题卡不做模糊——背景本身是平滑渐变，模糊看不出来，却会让低端机滚动掉帧。
- **数字等宽**：题号、题量、进度不再左右跳动。
- **代价**：文件 +6.0 KB，gzip 后 +1.7 KB（约 +2%）。全部是 CSS，没有多一次网络请求，也没有引入任何外部资源。

## 3.2fixed — 2026-10-11

### 修复｜底部按钮左右颠倒

选择题底部的两个按钮位置反了——「**提交**」在左、「**不会，看答案**」在右。

问题出在这：判分之后，底部的按钮是「上一题」（左）和「**下一题**」（右）。所以刷题时拇指会习惯性**一直按右下角**前进。可到了答完题、还没提交那一步，右下角变成了「不会，看答案」——**习惯性一按，就跳过了这道题**。

现在把顺序掉过来：

| 位置    | 未判分时            | 判分后     |
| ----- | --------------- | ------- |
| 左     | 不会，看答案          | 上一题     |
| **右** | **提交答案 / 确认提交** | **下一题** |

**右下角永远是「往前走」那个键**，拇指不用挪，也不用担心误按跳题。单选、多选、错题强化模式都改了。

## 3.1fixed — 2026-10-10

### 修复｜判分框的字母对不上

开了「选项乱序」以后，判分框里那句「**你选的是 X**」用的是题库里的**原始字母**，不是你屏幕上看到的顺序——于是会出现荒唐的一幕：**「你选的是 AC」「正确答案：AC」，却判你错。**

现在两处统一成**屏幕上的那套字母**：

| 判分框里的字  | 修复前            | 现在         |
| ------- | -------------- | ---------- |
| 你选的是 ？？ | 题库原始字母（跟屏幕对不上） | **屏幕字母** ✅ |
| 正确答案：？？ | 屏幕字母           | 屏幕字母       |

**判分本身一直是对的**（内部仍按原始字母比对），这次只是把显示对齐，不再自相矛盾。

### 新增｜多选题也能「不会，看答案」

以前只有单选题底部有「不会，看答案」，多选题不会就只能硬着头皮蒙。

现在多选底部也有这个按钮，点一下直接亮出答案、跳过本题。

### 新增｜单选题「确认提交」（可关）

以前单选题**点一下就直接判分**，手滑选错也没得改。

现在改成两步：

1. 点选项 → 高亮选中（**这时还能改选**）
2. 点「**确认提交**」→ 才判分

首页「其他」里新增开关 **「单选需确认」**，**默认开**。觉得单选多点一下慢，把它关掉，立刻回到原来的"点即判"。

### 一个小提示

上一版说过「别按 A/B/C/D 背答案，按选项内容记」。这条现在更成立了：**判分框里显示的字母，已经完全跟随你屏幕上的选项顺序**，不会再有两套字母打架的情况。

## 2.1fixed — 2026-10-10

### 新增｜错题强化 · 无限刷

刷到错题不用再等整轮刷完。测验首页会多出一个橙色的「错题强化 · 无限刷」按钮，按钮上直接写着当前范围里有多少道错题。

进去之后：正常题乱序循环出，**每做 3 道插一道错题**。

| 情况    | 结果                |
| ----- | ----------------- |
| 强化题答对 | 从错题池**永久移除**，不再出现 |
| 强化题答错 | 留在池里，过几道再来        |
| 普通题答错 | 自动加入错题池           |

- 第一题直接上强化题，不浪费时间
- 顶栏显示「第 N 题」，进度条按**攻克比例**走
- 强化题在题干上方有蓝色标识，写明池里还剩几道
- 池子清空 → 通关页；中途退出不丢进度

### 新增｜选项乱序（可关）

原来点卡片只能一路往下翻，想再背一遍没机会。
